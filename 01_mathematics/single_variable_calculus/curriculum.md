## 1. 定位

一元微积分是 MPCE 所有数学的起点。多元微积分、微分方程、傅里叶分析、变分法、数值分析，都是在它的基础上推广出来的。本模块只要求熟练掌握一元情形，多元和向量微积分在 [`calculus/`](../calculus/curriculum.md) 中学习。

## 2. 必须掌握的知识点

### 2.1 极限与连续

- [ ] 数列极限与函数极限，ε–δ 定义的含义
- [ ] 两个重要极限：$\lim_{x\to0}\frac{\sin x}{x}=1$，$\lim_{n\to\infty}\big(1+\frac1n\big)^n=e$
- [ ] 无穷小的比较与等价无穷小
- [ ] 连续性；闭区间上连续函数的最值定理、介值定理

### 2.2 导数与微分

- [ ] 导数的定义、几何意义（切线斜率）和物理意义（变化率）
- [ ] 求导法则：四则运算、链式法则、反函数、隐函数、参数方程求导
- [ ] 高阶导数
- [ ] 微分中值定理：罗尔、拉格朗日、柯西
- [ ] 洛必达法则
- [ ] 函数性态：单调性、极值、凹凸性、拐点、渐近线
- [ ] **泰勒公式**：见 [`taylor_formula.md`](taylor_formula.md)

### 2.3 积分

- [ ] 不定积分与原函数
- [ ] 定积分的定义（黎曼和）与性质
- [ ] **微积分基本定理**：见 [`fundamental_theorem_and_integration.md`](fundamental_theorem_and_integration.md)
- [ ] 积分技巧：换元法、分部积分、部分分式、三角代换
- [ ] 反常积分（无穷区间、无界函数）及其收敛判别
- [ ] 定积分的应用：面积、体积、弧长、功、质心

### 2.4 级数

- [ ] 数项级数的收敛判别：比较、比值、根值、积分判别法，交错级数
- [ ] 绝对收敛与条件收敛
- [ ] 幂级数与收敛半径
- [ ] 泰勒级数与常用函数的展开
- [ ] 傅里叶级数初步（在 [`differential_equations/`](../differential_equations/curriculum.md) 中展开）

### 2.5 简单微分方程

- [ ] 可分离变量方程、一阶线性方程
- [ ] 二阶常系数齐次线性方程（特征方程法）

## 4. 学时

约 60–80 h（已学过高等数学的同学以复习和查漏为主，约 30 h）。

## 5. 验收标准

- 能用 ε–δ 语言说明极限和连续，能用中值定理证明简单不等式。
- 能独立推导微积分基本定理和带余项的泰勒公式。
- 能熟练计算常见类型的不定积分和定积分。
- 能判断级数的敛散性，写出常用函数的泰勒级数并给出收敛范围。
