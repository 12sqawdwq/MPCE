# 学习策略：从工程数学回归到严谨推导（Learning Strategy）

> 适用对象：学过工程数学（线性代数、微积分、微分方程），但多已遗忘，且缺乏系统的证明/推导习惯的学习者。
> 目标：在 18–24 个月内达到高年级本科 → 研究生初年级水平，**既能推导，又能计算，还能迁移到工程问题**。

---

## 1. 诊断：工程数学背景的典型优势与缺口

| 维度 | 典型优势 | 典型缺口 | 对策 |
|---|---|---|---|
| 计算技巧 | 会套公式求积分、解常系数 ODE | 不清楚公式成立的条件 | 每个公式必须写出**假设条件**与**失效反例** |
| 概念理解 | 有几何与物理直觉 | 定义模糊（如"线性无关""收敛"） | 用**精确定义**重写关键概念，并给出一个正例与一个反例 |
| 推导能力 | 能跟随教材推导 | 无法独立从头写出；常跳步 | 采用"白纸复现"训练（§3.3） |
| 证明能力 | 几乎没有 | 不熟悉量词、逆否、归纳、反证 | 用 2–3 周集中补"证明工具箱"（§3.1） |
| 计算能力 | 可能用过 MATLAB | 不熟悉数值误差、稳定性、向量化 | Python 从第 1 周起交织进行（§4） |
| 概率 | 只记得少量公式 | 缺乏随机性直觉 | 用模拟先建立直觉，再补理论（§5） |

---

## 2. 核心原则：严谨但不陷入纯数学形式主义

**要达到的严谨性**：能够准确陈述定义与定理（含全部假设），能够独立完成工程与物理中**关键结论**的推导，能够判断一个结论在何种条件下失效。

**不追求的严谨性**：测度论层面的完整构造、拓扑学的一般理论、每个引理的全部证明细节。

### 2.1 "三层深度"决策规则

对每一个定理，在开始学习前先决定它属于哪一层：

| 层级 | 要求 | 适用定理示例 |
|---|---|---|
| **L1 必证（Prove）** | 能独立写出完整证明 | 谱定理（实对称情形）、最小二乘正规方程、Euler–Lagrange 方程、Galerkin 正交性、Kalman 滤波递推 |
| **L2 理解证明思路（Sketch）** | 能说出证明的关键步骤与核心想法 | SVD 存在性、Picard–Lindelöf 定理、Lax–Milgram 定理、Bloch 定理 |
| **L3 准确使用（Use）** | 能准确陈述并正确使用，知道假设何时被违反 | Fourier 级数收敛的 Dirichlet 条件、Sobolev 嵌入定理、Hohenberg–Kohn 定理 |

> 判据：如果一个定理的证明技巧会在后续主题中**反复出现**（如变分论证、能量估计、正交投影），则升级为 L1；如果证明依赖大量本项目不涉及的工具（如泛函分析深层结论），则降为 L3。

### 2.2 防止陷入形式主义的"止损线"

- 单个证明卡住 **超过 45 分钟**：查看提示或答案，标记该证明，3 天后再白纸复现。
- 单个主题的纯理论时间超过计划 **150%**：先进入计算实验，用数值结果反推理论，再回来补证明。
- 遇到需要测度论/泛函分析才能严格处理的内容：写出 L3 级陈述，标注 `[RIGOR DEFERRED]`，在知识图谱中记录，继续前进。

## 3. 重建推导与证明能力的具体方法

### 3.1 第 1–3 周：证明工具箱（Proof Toolkit）

与 Phase I 线性代数并行，每周约 2 小时：

| 工具 | 练习载体 |
|---|---|
| 量词与否定（$\forall, \exists$ 及其否定） | 改写"线性无关""极限""一致连续"的定义及其否定 |
| 直接证明与逆否证明（contrapositive） | 证明"若 $A$ 可逆则 $\ker A = \{0\}$"及其逆否 |
| 反证法（contradiction） | 证明 $\sqrt{2}$ 是无理数；证明不同特征值的特征向量线性无关 |
| 数学归纳法（induction） | 证明 Gram–Schmidt 过程产生正交基 |
| 构造性证明 | 证明有限维内积空间存在正交基 |
| "唯一性"论证模式 | 假设两个解，证明其差为零（ODE、Poisson 方程唯一性的共同模式） |

推荐参考：Velleman, *How to Prove It*（选读第 1–3 章即可）。

### 3.2 推导的"可审计性"标准

每一步推导必须能回答：**这一步用了什么？** 在推导旁边注明：

```text
(3) = (2) 两边对 x 求偏导                          [线性性]
(4) 交换积分与求导顺序                              [假设：被积函数及其偏导连续 — Leibniz 积分法则]
(5) 应用散度定理                                    [假设：Ω 有界，∂Ω 分段光滑]
```

这一习惯同时训练了"假设意识"，正是工程数学背景最缺乏的部分。

### 3.3 白纸复现训练（Blank-Page Reproduction）

1. 阅读并理解一个推导（不计时）。
2. 合上所有资料，在白纸上从头复现，**计时**。
3. 对照原文，用红笔标出：遗漏的假设、错误的步骤、卡住的位置。
4. 只针对卡住的位置重读，24 小时后再次复现。
5. 两次成功复现后，该推导在 `ROADMAP.md` 中才计入 `Completed` 的条件 ①。

### 3.4 "多路径推导"

关键结论至少用两种方法得到，以建立结构理解。例如：

- 最小二乘：① 微积分（梯度为零）；② 几何（正交投影）；③ 概率（高斯噪声下的最大似然）。
- 热方程：① 能量守恒 + Fourier 定律；② 随机游走的连续极限。
- 谐振子：① 级数解；② 阶梯算符（ladder operators）。

## 4. 早期交织 Python 数值计算

**原则：计算不是 Phase V 才开始的事，而是从第 1 周起理解数学的第二条通道。**

| 阶段 | Python 能力 | 与数学内容的交织方式 |
|---|---|---|
| Phase I 第 1–2 周 | NumPy 数组、向量化、Matplotlib | 可视化线性变换对单位圆的作用 → 引出特征向量与 SVD |
| Phase I 第 3–4 周 | `numpy.linalg`、浮点误差 | 比较正规方程与 QR 求最小二乘的数值误差 → 理解条件数 |
| Phase I 第 5–8 周 | SymPy 符号计算 | 用 SymPy 检验手工推导的导数、积分、Taylor 展开 |
| Phase II | `scipy.integrate`、自写 FDM | 数值解与解析解对照；观察 CFL 条件违反时的不稳定 |
| Phase III–IV | `scipy.sparse`、特征值求解器 | 双摆模拟、一维 Schrödinger 本征态 |
| Phase V 起 | 自研求解器、性能剖析 | 完整的 FDM/FEM 求解器、收敛阶验证 |

**三条纪律**：

1. **先推导后编码**：不写没有对应推导的代码。
2. **每个数值结果都要有验证基准**：解析解、守恒量、已知收敛阶或独立方法交叉对照。
3. **SymPy 只用于检查，不代替推导**。

## 5. 早期交织概率直觉

概率是统计力学、Kalman 滤波、Monte Carlo、贝叶斯推断与 AI 的共同瓶颈（见 [`prerequisite_map.md`](prerequisite_map.md)）。若推迟到 Phase VI 才系统学习，会在 Phase IV 统计力学处严重受阻。

**策略：先模拟、后公理（simulation first, axioms later）。**

| 时间 | 内容 | 形式 |
|---|---|---|
| Phase I 每周约 1 h | 随机变量、期望、方差、协方差矩阵 | 用模拟生成样本，估计统计量，观察样本量的影响 |
| Phase I 后半段 | 大数定律、中心极限定理（CLT） | 数值演示 $\bar{X}_n$ 的分布随 $n$ 的变化，测量 $O(n^{-1/2})$ 收敛 |
| Phase I 后半段 | 多元高斯分布 | 将协方差矩阵的特征分解与概率椭圆联系起来（衔接线性代数） |
| Phase II | 随机游走与扩散 | 随机游走的方差 $\propto t$ → 热方程的概率解释 |
| Phase IV 前 | 条件概率、贝叶斯公式、最大熵 | 为统计力学（Boltzmann 分布的最大熵推导）做准备 |

## 6. 诊断性自测（第 1 周完成）

不查资料作答，记录哪些能完成、哪些不能。结果用于微调 Phase I 的时间分配。

1. 给出向量组"线性无关"的精确定义，并写出其否定形式。
2. 证明：若 $A \in \mathbb{R}^{n \times n}$ 对称，则不同特征值对应的特征向量正交。
3. 计算 $f(x,y) = x^2 y + e^{xy}$ 的梯度与 Hessian。
4. 叙述散度定理（Gauss 定理），并写出它成立所需的条件。
5. 求解 $y'' + 4y = 0$，$y(0) = 1$，$y'(0) = 0$。
6. 两个独立的 $\mathcal{N}(0,1)$ 随机变量之和服从什么分布？请说明理由。
7. 用 NumPy 写出不使用 for 循环计算两个向量夹角的代码。

| 正确题数 | 建议 |
|---|---|
| 6–7 | 按计划推进；Phase I 可压缩 1–2 周 |
| 3–5 | 按计划推进；证明工具箱按 §3.1 完成 |
| 0–2 | Phase I 延长 2–3 周，先补线性代数与微积分计算基础（如 Strang 的入门教材） |

## 7. 主动阅读教材（Active Textbook Reading）

### 7.1 每节的三遍阅读法

| 遍次 | 目的 | 操作 | 时间占比 |
|---|---|---|---|
| 第一遍：侦察（Survey） | 建立结构地图 | 只读标题、定义、定理陈述与图表；写下 3 个"我想知道的问题" | 10% |
| 第二遍：精读（Engage） | 理解每一步 | 手推每个推导；遇到"易见""显然"必须自己补全；在每个定理旁边写出一个例子与一个反例 | 70% |
| 第三遍：重构（Reconstruct） | 形成自己的版本 | 合上书写一页摘要：核心定义、核心定理、关键推导骨架、与其他主题的联系 | 20% |

### 7.2 阅读时的主动提问清单

- 这个定义为什么要这样设置？去掉某个条件会发生什么？
- 这个定理的假设中，哪一个在工程问题里最容易被违反？
- 这个结论能否用一个 2×2 矩阵、一维问题或一个数值例子来检验？
- 这与我之前学过的哪个结构是同一件事？（记录到 `06_knowledge_graph/`）

### 7.3 推荐的主线教材组合（每个主题选一本作为主线，另一本作为参照）

| 主题 | 主线 | 参照 |
|---|---|---|
| 线性代数 | Strang, *Introduction to Linear Algebra* | Axler, *Linear Algebra Done Right* |
| 向量微积分 | Marsden & Tromba, *Vector Calculus* | Schey, *Div, Grad, Curl, and All That* |
| 数学物理方法 | Boas, *Mathematical Methods in the Physical Sciences* | Riley, Hobson & Bence, *Mathematical Methods for Physics and Engineering* |
| PDE | Strauss, *Partial Differential Equations: An Introduction* | Evans, *Partial Differential Equations*（仅查阅） |
| 概率 | Blitzstein & Hwang, *Introduction to Probability* | Bertsekas & Tsitsiklis, *Introduction to Probability* |
| 数值方法 | Trefethen & Bau, *Numerical Linear Algebra* | Heath, *Scientific Computing: An Introductory Survey* |

## 8. 常见陷阱与应对

| 陷阱 | 症状 | 应对 |
|---|---|---|
| 收藏代替学习 | 收集大量资料，但推导一页都没写 | 每周至少完成 2 次白纸复现；以产出而非阅读量计进度 |
| 完美主义停滞 | 在某个证明上耗费数天 | 执行 §2.2 止损线 |
| 只算不推 | 代码能跑，但说不清楚为什么 | 执行"先推导后编码"纪律 |
| 只推不算 | 推导完整，但从未在数值上验证 | 每个 L1 推导必须配一个数值检验 |
| 广度焦虑 | 想同时学 7 个领域 | 应用领域只在 Apply 环节做映射，不提前展开 |
| 智能体依赖 | 读懂了 AI 写的推导就以为自己掌握 | 严格区分内容状态与掌握状态（见 `ROADMAP.md` §0） |
